# 05: Drag and drop

**What to build:** Sending and receiving become one gesture. Dropping files from the system file manager onto the Next pane sends them into the shown folder, or into the Next subfolder under the cursor. Dragging entries from the Next pane to the Local pane receives them. Dragging out of the application to the system file manager is not supported.

**Blocked by:** 04 (Send and receive)
