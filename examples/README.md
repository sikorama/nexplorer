# Examples

This folder is meant to hold the NextBASIC launcher programs written by the repository owner. They are to be supplied by the owner and are not included yet.

They are meant to start the `.sync5` dot command in one step, without typing it:

- `sync-wrap.bas`: a NextBASIC program that runs `.sync5 -l` so that the Next connects to nexplorer when the program is selected from the Next's file browser.

Copy the programs to the Next's SD card, next to your other programs.
